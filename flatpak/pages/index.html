T3 Code Flatpak

Unofficial package for x86_64 Linux

T3 Code runs inside Flatpak while agents, terminals, Git, and project tools run in your normal host development environment.

Install T3 Code

Accept the prompt to add the T3 Code repository for updates and to keep the app available to reinstall after uninstalling.

Or install T3 Code system-wide from a terminal:

flatpak install --system https://t3code.thomasberrios.com/com.t3tools.t3code.flatpakref

You can also add the repository separately and install T3 Code later from your software store.

Source and release notes are available on GitHub.
